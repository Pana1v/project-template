# Agent docs

Context for coding agents that the code cannot show. Humans read `docs/`; agents read
both. Keep each file short and true: a wrong line here is worse than a missing one.

| File | Covers |
|---|---|
| `architecture.md` | module map, data flow, where state lives |
| `conventions.md` | code style, testing rule, commit format |
| `audit.md` | how to audit the repo, this project's high-cost areas, report format |
